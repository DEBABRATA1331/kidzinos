# Kidzinos App - Powered by Crazy XYZ ⚡

## 🚀 How to Open
Just open `index.html` in any browser. For best experience, use Chrome DevTools > Toggle Device Toolbar (Ctrl+Shift+M) and select iPhone 14 Pro (390×844).

## 📱 App Screens
1. **Splash** – Animated Crazinos splash with loading bar
2. **Login** – Mobile + OTP flow (enter any 10-digit number, then any 6-digit OTP)
3. **Register** – Name, Email, DOB, City
4. **Home** – Banner, challenge cards, shop, XYZ Studio
5. **Play** – Daily Drill, Weekly Stash, Crazy War cards
6. **Quiz** – Timed quiz with streak bonus and floating point rewards
7. **Result** – Score, rank, share & challenge friend
8. **CSI** – Crazy Skill Index with circular gauge + leaderboard
9. **Watch & Earn** – Video list with 80% progress coin reward
10. **Store** – Zino Coin products + Shopify section + Crazy Pass
11. **Profile** – User info, stats, menu
12. **Crazy Pass** – Free / Monthly ₹199 / Annual ₹999 subscription

## 🎨 Design
- Dark navy theme (#0F0F1A)

## 🪙 Zino Coins System
- Earn via Daily Drill, Watch & Earn
